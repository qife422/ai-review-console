# Demo materials

All screenshots show fixed-seed synthetic data generated by this repository. They do not contain company confidential information.

- `screenshots/overview-desktop.png`: operating overview and risk distribution
- `screenshots/case-detail-desktop.png`: explainable findings after a human decision
- `screenshots/queue-mobile.png`: responsive review queue
- `../docs/DEMO_SCRIPT.md`: six-minute presentation script
- `../examples/reports/`: JSON, HTML and PDF sample decision reports

The visible `Built on Langflow` attribution is intentional. Langflow is the workflow engine; the Review API remains the system of record for approvals and audit events.
